Ejercicio 1 - Acumulador y contador

Crea un programa que permita introducir 5 números. El script debe calcular la suma de todos ellos y mostrar cuántos de esos números son mayores de 100.

Ejercicio 2 - Cálculo de IVA mediante funciones

Crea un programa donde se introduzca el precio de un artículo. Utiliza una función para calcular el IVA y el precio total (con IVA incluido). El resultado debe aparecer redondeado a dos decimales.

Ejercicio 3 - Manipulación dinámica del DOM

Crea una página con dos campos de texto para introducir números. Calcula la suma de ambos y muestra el resultado en un nuevo campo de texto que deberás crear dinámicamente desde TypeScript.

Ejercicio 4 - Creación de clases y objetos

Define una clase Alumno con las propiedades nombre, edad y curso. El programa debe instanciar un objeto con los datos: Nombre="Pedro López", Edad=18, Curso=1CFSJ y mostrarlos por pantalla.

Ejercicio 5 - Implementación de clases compuestas y alert

Crea una clase llamada Curso que implemente la descripción extendida del curso: "Primer curso de grado superior de DAW". Utilizando la clase Alumno anterior, muestra mediante un alert el mensaje formateado con el nombre, edad, código de curso y descripción completa.
