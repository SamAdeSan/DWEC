Ejercicio 1 - Carga de fichero de texto con AJAX

Realiza un ejercicio en el que, mediante el método $.ajax, se cargue un fichero de texto externo.

  • Si la transferencia de la información se realiza correctamente, el contenido del fichero se mostrará dentro de un contenedor de la página.
  • Si la transferencia no se realiza correctamente, se mostrará un mensaje general de error en pantalla.

Ejercicio 2 - Carga de fichero PHP con loader y control de errores

Utilizando el método $.ajax, carga un fichero PHP que muestre la fecha y hora actual del sistema, simulando una carga lenta.

  • Antes de mostrar la información, deberá aparecer un icono o imagen típica de carga.
  • Si la transmisión se realiza correctamente, se mostrará la información recibida en pantalla.
  • Si se produce un error, se deberá mostrar el código de error correspondiente.

Ejercicio 3 - Carga y ejecución de un fichero JavaScript

Utilizando el método $.ajax, carga un fichero JavaScript externo y ejecútalo en el lado del cliente una vez se haya recibido correctamente.

Ejercicio 4 - Envío de formulario con $.get y serialize

Crea un formulario que contenga los campos usuario y clave. Mediante el método $.get, envía los datos del formulario a un fichero PHP utilizando el método serialize.

  • Si el usuario es “pepe” y la clave es “hola”, se mostrará el mensaje “usuario correcto”.
  • En cualquier otro caso, se mostrará el mensaje “usuario incorrecto”.

Ejercicio 5 - Consumo de API REST con getJSON

Utiliza el método getJSON para consumir la API REST de países disponibles en la siguiente dirección: https://restcountries.eu/

  • Se deberán obtener y mostrar los países pertenecientes a Europa.
  • Si se produce algún error, se mostrará en pantalla el código de error y el texto descriptivo del error.
