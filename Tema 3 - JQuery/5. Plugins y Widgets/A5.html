Ejercicio 1 - Plugin para desaparecer párrafos

Tenemos una página con varios párrafos y un botón desaparecer. Crea un plugin sencillo para que al pinchar sobre el botón desaparezcan todos los párrafos de la pantalla.

Ejercicio 2 - Crear un plugin personalizado

Crea un plugin nuevo, siguiendo las normas de creación de jQuery, para que haga lo que tú programes.

Ejercicio 3 - Plugin libre con opciones (extend)

Crea un plugin libre que utilice la configuración de opciones mediante $.extend().

Ejercicio 4 - Página con plugin carrusel

Crea una página web que utilice un plugin de carrusel para mostrar varias imágenes que tú elijas.

Ejercicio 5 - Página con widget acordeón

Crea una página web utilizando el widget acordeón de jQuery UI.

Ejercicio 6 - Página con plugin y widget a elección

Crea una página web combinando un plugin y un widget que tú selecciones y programes.
