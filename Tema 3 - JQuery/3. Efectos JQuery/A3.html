Ejercicio 1 - Aplicación de efectos jQuery sobre una imagen

Crea una página web que contenga una imagen y varios botones. Mediante dichos botones, el usuario deberá poder aplicar todos los efectos de jQuery vistos en clase sobre la imagen: efectos básicos (show, hide, toggle), efectos de fundido (fadeIn, fadeOut, fadeToggle), efectos de deslizamiento (slideUp, slideDown, slideToggle) y el método animate.

Ejercicio 2 - Mensaje con efecto de fundido

Diseña una página con un fondo de color azul en la que se muestre, centrado en la pantalla, un mensaje con el texto “Bienvenidos a esta aplicación”.

La página deberá incluir dos botones: Saludo, que hará que el mensaje pase de transparente a opaco mediante un efecto de fundido, y Despedida, que realizará el efecto contrario.

Ejercicio 3 - Movimiento animado de un cubo

En la pantalla deberá aparecer un cubo que se mueva automáticamente describiendo la trayectoria de un cuadrado utilizando animaciones con jQuery.

La página contará con dos botones: Parar Efecto, que detendrá todas las animaciones del cubo, y Iniciar Efecto, que reanudará su movimiento.

Ejercicio 4 - Cambio de color con animate

Utilizando el método animate de jQuery, crea un efecto que permita cambiar el color inicial de todas las etiquetas h1 del documento al hacer clic sobre ellas.

Ejercicio 5 - Uso de la cola de efectos con queue

Utilizando el método queue de jQuery para acceder a la cola de efectos, aplica sobre una capa (puede reutilizarse el cubo del ejercicio anterior) los siguientes efectos, en este orden: animate, css y animate.

Entre cada efecto se deberá utilizar un delay para que la transición entre ellos sea claramente visible.
